1Arah

Satu tempat gratis tempat siapa pun bisa menjawab dalam satu menit, dengan sumber bertanggal: siapa pemain energi terbarukan di Indonesia, siapa memasok dan mendanai siapa, proyek apa yang sudah jalan, dan siapa pakarnya.

Masalah yang dijawab

  • METI mengklaim 1.800+ anggota dan 20+ mitra, tetapi situs metiires.or.id hanya menampilkan 12 logo anggota dan 12 logo mitra. Tidak ada direktori, peta, pencarian, atau relasi.
  • Ekosistem tersebar: peta hanya peta, riset hanya riset, dataset hanya dataset. Tidak ada satu tempat yang menghubungkan orang, lembaga, perusahaan, kampus, proyek, pembiaya, dan regulasi.
  • Angka berbeda antar dokumen (potensi panas bumi 23,2 vs 23,9 vs 24 GW). Tanpa atribut tanggal dan sumber, angka METI mudah dipatahkan.

3Fase dan peta jalan

Nilai terlihat paling cepat: kode direktori yang sudah ada jalan lebih dulu (F0), lalu sensus (F1), rantai dan cerita (F2), lalu pintu terbuka (F3).

F0 Porting selesai

Repo, Worker, D1, R2, login, admin akun, RLS, direktori lama berjalan di METI, i18n kerangka. Migrasi 0001 sampai 0008 sudah diterapkan di produksi dan situs tayang di direktori.metiires.or.id.

Lulus bila: uji RLS hijau, /direktori tampil di 1280 dan 390 px. Tombol dummy dibatalkan (K15).

F1 Sensus berjalan

Panen gelombang 1, kurasi, sensus perusahaan, profil bersumber, peta, metode. Prioritas K17: pelacak proyek, rantai PLTS, profil proyek dan perusahaan, pengurus METI, profil sendiri dan kelompok orang (K19).

Lulus bila: 300+ entitas bersumber, 0 baris tanpa sumber, skor keyakinan tiap profil.

F2 Rantai dan cerita berjalan

Rantai pasok, pembiaya, BUMN, data center, desa, wilayah, kebijakan, cerita data. Beberapa halaman sudah tayang: rantai PLTS, wilayah, regulasi, kalender, ASEAN, berita.

Lulus bila: tiap halaman punya Jawaban singkat, Cara menghitung, dan tanggal beku.

F3 Terbuka ditunda

Klaim profil, daftar mandiri, API terbuka, pencocokan kebutuhan. Pendaftaran mandiri (JM-R02) ditunda pemilik pada 7 November 2026: selama masa uji, akun dibuat manual oleh admin.

Lulus bila: disetujui Pengurus Harian (C-01).

6Armada agent

Delapan belas agent, semuanya punya model: tertulis. Sub-agent tanpa model tertulis diam-diam ikut model induk, jadi itu ditolak gerbang.

Kebijakan model

opus

Perencana saja

Rencana, keputusan arsitektur, kontrak inti, review akhir, commit dan push. Tidak menulis kode massal dan tidak membaca berkas besar utuh.

sonnet

Pengerja dan pemeriksa nalar

Kode per wilayah berkas, dokumen, riset, pengulas keamanan, kinerja, dan INP.

haiku

Pemeriksa pola

Cek rute, migrasi, higiene repo, angka, hak, i18n, dan pencarian murah.

Naik ke Opus per panggilan hanya untuk hak.js, sandi, atau migrasi berisiko, dengan alasan tertulis. Env CLAUDE_CODE_SUBAGENT_MODEL=sonnet menjadi jaring pengaman untuk agent bawaan. Meteran: npm run token:ukur.

Roster

AgentModelLingkup

Aturan kerja

  • Maksimal 5 agent paralel, dan kontrak inti dikunci dulu sebelum fan-out.
  • Satu pemilik per berkas: tidak ada dua penulis di berkas yang sama.
  • Laporan balik agent 15 baris atau kurang; rincian ditulis ke berkas.
  • Brief berisi path berkas dan kriteria selesai, bukan domain.
  • Agent yang sama masih relevan: lanjutkan lewat SendMessage, jangan agent baru.
  • Penulis kode bukan pengulasnya. Verifier adalah peninjau-bersih dengan konteks bersih, memeriksa sinyal nyata, bukan klaim.
  • Pengulas melapor, tidak memperbaiki sendiri. Pengerja pemilik berkas yang membetulkan.
  • Sub-agent tidak commit, push, atau deploy. Migrasi D1 produksi dan unggah R2 produksi dijalankan pemilik.

7Gerbang mutu

Aturan tanpa gerbang mekanis dianggap belum jadi. Gerbang mekanis jalan lebih dulu dari review manusia.

Suite

npm run uji

Menjalankan node --test: sekitar 236 uji node:test di folder tests/, tanpa framework tambahan. CI memakai alur yang sama di .github/workflows/uji.yml.

Prinsip

Yang salah DITOLAK

Tiap aturan hak, CHECK, dan trigger punya uji bahwa peran atau data yang salah ditolak. Tiap fungsi, rute, dan skrip baru terdaftar di tests/cakupan.json.

Pemindai data pribadi potret

Repo ini publik, jadi data pribadi tidak boleh masuk repo, public/, atau potret publik. tests/potret.test.mjs menjalankan selftest() dari scripts/pipa/potret.mjs, yang memeriksa tiga hal: pemindai data pribadi, pemecahan potret di batas 2 MB, dan pembagian potret ke tiga lapis akses (publik, anggota, pengurus). Pembagian lapis dibuat saat potret dibangun, bukan disaring di klien.

Tinjauan tangkapan layar

Layar dinyatakan selesai hanya setelah dilihat. Tangkapan diambil di 1440 dan 375 px, terang dan gelap, bahasa ID dan EN; temuan diperbaiki lalu diulang. Tangkapan disimpan di tests/layar/tangkapan/ dan tidak di-commit bila berisi data nyata. Setelah itu audit desain, data terburuk (nama panjang, kosong, angka ekstrem), aksesibilitas WCAG AA, dan review terpisah oleh peninjau-bersih.

Larangan tetap

  • Tanpa data pribadi di lapis Publik atau di repo, dan tanpa rahasia atau account_id.
  • Tanpa angka tanpa sumber dan tanggal; angka turunan berlabel EST.
  • Tanpa menyalin teks, estimasi, atau logo pihak lain secara massal.
  • Tanpa panen situs yang melarang robot tanpa izin.
  • Tanpa tombol, kolom, atau rute data dummy (K15).
  • Gerbang, ambang, dan uji tidak boleh dilemahkan untuk meloloskan kerja sendiri.
