# GLOSARIUM: 65 fitur pilihan pemilik

Hanya istilah yang baru atau yang dipakai dengan arti khusus di modul ini. Istilah lain mengikuti GLOSARIUM induk.

| Istilah | Arti di modul ini |
| --- | --- |
| Butir | satu dari 65 fitur pilihan pemilik, bernomor menurut daftar 100 |
| Gelombang | kelompok kerja menurut ketergantungan: 1 layar dan rumus, 2 tabel dan rute, 3 menunggu hal di luar kode |
| ADA, SEBAGIAN, BELUM | kelas hasil pemetaan 15 Nov 2026; berbasis grep, belum diuji di browser |
| Rumah | halaman yang sudah ada tempat sebuah butir ditambahkan |
| Kiriman yang ditinjau | isian pengguna yang baru tampil ke orang lain setelah disetujui admin |
| Isian pengguna | nilai yang diketik pengguna; tidak punya bawaan |
| Emisi dihindari | energi terbarukan dikali faktor emisi sistem; bukan kredit karbon bersertifikat |
| REC | sertifikat energi terbarukan, 1 REC = 1 MWh |
| Geser beban | mengisi baterai saat tarif rendah dan memakainya saat tarif tinggi |
| Pembiayaan campuran | gabungan hibah, pinjaman lunak, pinjaman komersial, dan ekuitas |
| Konsumsi spesifik | liter BBM per kWh yang dihasilkan genset |
| Papan minat | daftar pihak yang berminat, tanpa transaksi lewat platform |
| Tiket | bukti pendaftaran event ber-QR, sekali pakai untuk mencatat hadir |
| Hadir | status pendaftar yang QR-nya sudah dipindai admin |
| Jangkauan | jumlah kunjungan halaman event dan klik ke sponsor |
| Rasio terpasang | kapasitas terpasang dibagi potensi |
| Plafon kontras | jumlah pasangan warna gagal sesudah audit; tidak boleh naik |
